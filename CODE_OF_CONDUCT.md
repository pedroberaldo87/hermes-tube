# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Read it at that address; it applies to everyone who takes part in the repository: issues, pull requests, discussions and any other space where the project is represented.

In short: be respectful, accept feedback gracefully, and do not harass anyone.

## Reporting a problem

If someone behaves in a way that breaks the Covenant, tell the maintainer privately. Use the same channel as for security reports: the **Security** tab of this repository, then **Report a vulnerability**. Say in the first line that it is a conduct report, not a vulnerability, so it is handled as one. If that button is not available, open an issue that says only "conduct report, please contact me", with no details, and I will set up a private channel.

Reports are read by the maintainer and kept private. The enforcement steps in the Covenant (correction, warning, temporary ban, permanent ban) are the ones used here.
