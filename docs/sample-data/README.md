# Sample data

Invented channels and videos used for the screenshots and the demo video. Nothing here is a real
YouTube channel or video: the names and titles were written for this project and the thumbnails were
generated for it. The ids are synthetic (`UCsample…`, `smp…`) and do not resolve on YouTube.

- `catalog.json`: 6 folders, 18 channels, 40 videos and one topic tab ("Wildlife Documentaries",
  7 more channels, 14 videos), plus 2 local playlists ("Weekend projects", "Slow evenings") made
  only of catalog videos.
- `thumbs/<video id>.jpg`: one 960×540 thumbnail per video.

The plugin does not ship or read this folder. Its built-in demo is a separate list of public channels
(`plugin/data/demo_channels.json`).
